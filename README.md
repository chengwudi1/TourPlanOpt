# TourPlanOpt

**几个人打开同一个链接，一起把一趟旅行排好——地点即时同步，路线自动算最优。**

在线使用 → **<https://chengrm.online/tourplanopt>**（手机浏览器「添加到主屏幕」即可当应用用）

![行程页：海报头封面、当天的时间线、地图上的路线与同伴位置](assets/trip-desktop.png)

## 为什么是它

多数行程工具解决的是「去哪玩」，而真正卡住一趟出行的是另外两件事：**几个人的意见对不齐**，以及**一天里七八个地点的先后顺序没人算得清**。

TourPlanOpt 只把这两件事做深。协作在这里不是注册之后才解锁的附加功能，它就是入口本身——一个链接进来，就能同时改同一份行程。

这个工具先服务自己：出游时真的拿它排程，功能边界由实际用起来别扭的地方决定，而不是由功能清单决定。

## 能做什么

### 一起排 · 实时协同

- 打开同一个链接即进入同一份行程，彼此添加的地点、改的时间即时可见
- 谁选中了哪张卡片、谁正停在地图上哪一站，头像当场跟着动；同伴离开之后不留幽灵头像
- 中途掉线、切到后台再回来，落下的改动与消息自动补齐，不需要手动刷新
- 同行留言按「哪天哪一站」锚定：问一句「这家要不要留」不必再另开群聊

### 排得顺 · 自动算路

- 一键把一天的游览顺序排到最优，14 站以内求精确解；可锁定某站、指定起点与终点，让优化器绕着它排其余地点
- 任何增删改之后，服务端就地重算当天的到达与离开时间并广播——**不点「优化」也有一条完整时间线**，与固定时间冲突时给出告警
- 距离实测带缓存与不可达负缓存，配额消耗在界面上可观测：同一趟行程反复优化不会反复烧配额
- 默认用直线距离打分（零 API 调用），要看真实路况时再切驾车或步行

### 走得完 · 一趟出行的其余部分

- 出行清单：一键灌一份常用清单，打勾进度同时出现在行程页、卡片标签和首页门面上
- 费用与 AA：预算、分类小计、超支告警；每笔可选分摊人，按人头折算成应收应付，并给出最少笔数的转账建议，结算明细一键复制成群里能看的文本
- 首页是仪表盘而不是列表：按「规划中 / 回来了还没收尾 / 已完成」分档，门面卡回答的是「这趟还差什么」——几天后出发、清单还差几项、钱花到哪了
- 每天带那天的天气，长列表滚动时与「第 N 天」一起吸顶
- 想去清单与城市推荐：先存着，想好了再排进某一天；地图右键或长按选点也能直接加
- 对话式助手：说一句话就落成界面动作（「门票花了 240」「最后一天别排太满」），认不出的部分回问而不是猜；支持语音输入
- 底部一键复制文字版行程，直接贴进群聊
